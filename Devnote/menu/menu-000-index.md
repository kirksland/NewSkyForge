# Menu Docs Index

## Purpose

Index central des pages “menu” pour le module Python `skyforge.forge_tools`.

## Intentions

Ces menus sont là pour **simplifier l’usage de SkyForge** au quotidien.
L’idée est d’offrir un point d’entrée clair, personnalisable et cohérent.

Ils servent à :
- Construire un **menu runtime** adapté à ton workflow.
- Donner une **vue d’ensemble** de tes tools, HDA et du package.
- Centraliser l’accès aux outils sans se perdre dans l’UI Houdini.

En résumé, `forge_tools` fournit un **pipeline de menu** :
éditeur → JSON → menu runtime, pour organiser et lancer tes outils proprement.
