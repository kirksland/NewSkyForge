Recap 2026-03-11

Nouveaux composants
1. FeatureHub (dispatcher)
   - Fichier: python/skyforge/forge_states/feature_hub.py
   - But: dispatcher les hooks des features pour reduire le boilerplate.

2. HoverMoveFeature (pipeline hover)
   - Fichier: python/skyforge/forge_states/features/hover_move_feature.py
   - Move compatible hover (point/edge/face).
   - Actif uniquement en mode MOVE.

3. HoverDrawFeature
   - Fichier: python/skyforge/forge_states/features/hover_draw_feature.py
   - Draw compatible hover, LMB ajoute un point, drag deplace le dernier.
   - Commit de courbe possible (reset de la courbe active).

Nouveaux states de test
1. edit_modular_state
   - Hover + move, sans dispatcher.
2. dispatcher_modular_state
   - Hover + move, dispatcher actif.
3. hover_curve_modular_state
   - Draw + Move (modes D/M), hover compatible.
   - Commit curve via Enter.

Menu et hotkeys hover
- HoverGadgetFeature gere un menu d'actions et hotkeys (AZERTY):
  - & = Point
  - é = Edge
  - " = Face
- Le menu s'adapte aux modes autorises (onMenuPreOpen).

HUD
- HoverGadgetFeature expose un HUD minimal (mode + keys).
- FeatureHub sait aggreger les fragments HUD.
